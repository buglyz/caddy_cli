# 重整 Go CLI 纵向菜单分组

日期：2026-07-26

## 目标

以 `main` 分支旧 Shell 菜单为基准，原样迁移交互菜单的纵向分类、标题和主编号，同时保留 Go 版新增能力。

## 边界

- 主菜单按 `main` 的“快速操作 / 站点管理 / 系统管理”分组，使用 `1–8` 编号。
- 服务控制与配置管理合并为 `6. 服务与配置`。
- Go 版独有操作追加在对应子菜单，不覆盖 `main` 的原编号。
- 不修改固定 Release `v0.2.0`，只更新 `refactor/go` 与滚动版 `go-latest`。
- 不修改生产 Caddy 配置或服务，不启用 Cloudflare。
